Packet Guru provides a suite of network and privacy tools that let users check their public IP address, perform DNS lookups, run port scans, trace routes, and evaluate browser fingerprinting. The site offers utilities such as SSL certificate checking, encrypted client hello (ECH) detection, MAC address lookup, and various IP geolocation services. It also hosts guides for AI agents and crawlers, and presents a privacy & trust index to help understand how websites perceive a visitor's connection. The platform is an independent project not affiliated with any corporate entity, aiming to increase transparency of internet connectivity and security.
